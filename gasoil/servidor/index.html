Conectar la app con la hoja

Se hace una sola vez, mejor desde una computadora, con la cuenta de Google donde está la hoja «Gasoil Paso Nuevo».

  1. Toque este botón para copiar el código:
  2. Abra script.google.com (crea un proyecto nuevo). Póngale de nombre Servidor Gasoil.
  3. Borre lo que trae escrito y pegue el código. Toque el disquete para Guardar.
  4. Arriba elija la función probar y toque Ejecutar. Google pide permiso: Revisar permisos → su cuenta → Configuración avanzada → Ir a Servidor Gasoil → Permitir.
  5. Toque Implementar → Nueva implementación. En el engranaje elija Aplicación web. En «Quién tiene acceso» elija Cualquier usuario. Toque Implementar.
  6. Copie la URL de la aplicación web (empieza con https://script.google.com/macros/s/…) y mándesela a Claude.
